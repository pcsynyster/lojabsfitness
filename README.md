# BS Fitness

Site da loja BS Fitness, moda fitness feminina em Parnamirim-RN.

- Catálogo com filtros, seleção de tamanho e cor
- Sacola de compras salva no navegador
- Pedido finalizado direto no WhatsApp da loja
- Tabela de tamanhos, formas de pagamento, provador em vídeo e links para Instagram, TikTok e Grupo VIP

Feito em HTML, CSS e JavaScript puros (`index.html`, `style.css`, `script.js`). Preços meramente ilustrativos.
